# Dot Motion Studio 한국어 설명 영상

24초 무음 영상입니다. 아래 내용은 영상의 자막과 시각적 내용을 텍스트로 풀어 쓴 것입니다.

## 00:00–00:05 · 입력 PNG

미리 준비한 투명 골프공 이미지를 실제 엔진에 넣었습니다.

입력은 `golf-ball-input.png`, 96×96픽셀의 RGBA PNG 한 장입니다. 배경의 체크무늬는 투명 영역을 구별하기 위한 표시입니다. 이 골프공 이미지는 데모 준비 단계에서 새로 생성하고 축소했으며, Dot Motion이 공 이미지를 생성한 것은 아닙니다.

## 00:05–00:12 · 2D 이동

공의 모양은 그대로, 매 프레임 X 방향으로 12픽셀 이동합니다.

프레임 수는 16, X 이동량은 +12픽셀, Y 이동량은 0, 재생 속도는 12fps입니다. 각 프레임의 크기는 276×96픽셀입니다. 같은 골프공이 왼쪽에서 오른쪽으로 일정하게 이동하고, 마지막 프레임 다음에는 처음으로 돌아갑니다. 포즈와 원본 픽셀은 유지됩니다.

## 00:12–00:18 · 아틀라스

16프레임을 가로 4칸에 배치하고, 좌표와 타이밍을 JSON에 기록합니다.

실제 PNG 아틀라스는 1104×384픽셀이고 4×4칸입니다. 프레임이 왼쪽 위부터 순서대로 배치되어 있습니다. 영상에 보이는 격자와 01–16 번호는 설명을 위해 얹은 표시이며 실제 출력 PNG에는 없습니다.

## 00:18–00:24 · 내보내기

PNG·JSON·ZIP이 도구의 출력입니다. 이 영상은 출력물로 따로 편집했습니다.

결과물은 투명 PNG 아틀라스, 프레임 좌표·크기·재생 정보를 담은 JSON, 개별 PNG 16장과 JSON 1개를 담은 ZIP입니다. 이 파일들을 게임이나 다른 편집 도구의 입력으로 사용할 수 있습니다.

이 설명 영상은 실제 로컬 엔진 출력으로 제작한 자료입니다. 앱 화면 녹화나 라이브 MCP 연결 성공 시연이 아닙니다. MP4와 GIF는 별도 FFmpeg 작업으로 만들었으며 엔진의 기본 출력 형식이 아닙니다. 골프 스윙이나 새 포즈 생성이 아닌 단순 2D 이동을 보여줍니다.
