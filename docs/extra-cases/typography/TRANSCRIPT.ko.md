# 영상 설명 · 골프의 순간

10초, 무음, 한국어 자막이 영상 안에 들어 있습니다. 720×720 정사각형 영상입니다.

## 00:00–00:02 · 준비된 한글 모션

“폰트로 16장의 모션 프레임을 먼저 준비했어요”

한글 “골프의 순간”을 정확하게 표시하기 위해 Noto Sans CJK KR 폰트로 입력 프레임을 만들었습니다. 다섯 글자가 서로 다른 타이밍과 방향에서 등장합니다. 이 폰트 렌더링과 글자 움직임은 엔진 실행 전 별도로 준비한 것입니다.

## 00:02–00:08 · 타이밍을 재생하다

“실제 엔진으로 나눈 프레임을 8 FPS로 재생해요”

실제 로컬 엔진이 4×4 입력 시트를 16개 PNG로 나눈 결과를 순서대로 재생합니다. 엔진은 움직임을 새로 만들지 않고, 준비된 프레임과 투명도를 유지합니다. 글자는 같은 좌표에 정렬되고 잠시 유지한 뒤 다시 시작합니다. 영상에는 세 번의 2초 재생이 포함됩니다.

## 00:08–00:10 · 좌표와 투명도, 그대로

“PNG 아틀라스 · JSON · 프레임 ZIP으로 저장해요”

결과는 960×512 PNG 아틀라스, 좌표·타이밍 JSON, 개별 PNG 16장이 든 ZIP입니다. 모든 입력 셀과 출력 프레임의 RGBA 픽셀 일치를 확인했습니다. 고정 캔버스를 유지했으므로 글자의 기준 위치가 바뀌지 않습니다.

## 제작 범위

영상 속 글자 모션은 외부에서 준비했고, 엔진은 프레임 추출과 내보내기에 사용했습니다. 실제 엔진 출력 PNG로 별도 편집한 설명 영상이며 화면 녹화나 라이브 MCP 시연이 아닙니다. MP4는 FFmpeg로 만들었고, 엔진의 기본 동영상 내보내기 기능을 의미하지 않습니다. MP4에는 배경이 합성되어 있고, 투명도는 PNG 결과물에 보존됩니다.
